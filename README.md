# ✂️ PliersPlus（LinkCut）

> 剪刀工具增强 + 反向连接工具

---

## 📌 功能概述

本模组为《缺氧》官方剪刀工具（Disconnect Tool）提供两项重要增强：

- **范围框选模式**：将官方原有的单线模式（Line）扩展为可拖拽的矩形框选模式，可批量断开连接。
- **反向连接工具（LinkCut）**：新增一个独立的工具，用于**恢复**断开的电线、管道等连接。

---

## 🔧 详细说明

### 1. 剪刀工具增强（Disconnect Tool）

- 官方默认：单线模式（Line），拖拽距离仅 1×2 格。
- 本模组修改：将模式改为**框选模式（Box）**，支持任意矩形范围。
- **快捷键**：按住 `Shift` 拖拽可切换为 **无限长单线模式**（1×∞），方便快速沿直线操作。

✅ 现在你可以一次性剪断大片区域内的所有连接，极大提高效率。

---

### 2. 连接工具（LinkCut）

- 这是官方剪刀工具的**逆向操作**。
- 功能：在断开的电线、管道之间重新建立连接。
- 模式：仅支持**单线模式（Line）**，无限长（1×∞），拖拽即可恢复连接。

🔗 适用于修复因误操作或布局调整导致的连接断裂。

## 🌐 英文版 / English

### ✂️ PliersPlus（LinkCut）

> Enhanced Disconnect Tool + Reverse Connect Tool

---

### Features

- **Box Selection Mode** for the official Disconnect Tool – drag a rectangle to disconnect multiple connections at once.
- **Connect Tool (LinkCut)** – a reverse tool to restore broken connections.

---

### Details

#### 1. Disconnect Tool Enhancement

- Original: Line mode, 1×2 cell range.
- Modified: Box mode, arbitrary rectangle.
- **Shortcut**: Hold `Shift` while dragging to switch to **infinite line mode** (1×∞).

#### 2. Connect Tool (LinkCut)

- Reverse operation of Disconnect Tool.
- Restore connections between utilities.
- Mode: Line only, infinite length (1×∞).
